# Attendance Tracking System

A simple terminal-based Attendance Tracking System built with Python.  
This program allows users to record student attendance, view attendance records, and display an attendance summary.



 Features

- Mark student attendance
- Prevent duplicate attendance entries
- View all attendance records
- Display attendance summary
- Simple menu-driven interface


 Technologies Used

 Python 3


Program Functions

1. Mark Attendance
Allows the user to:
Enter a student's name
Mark the student as:
Present
Absent

The system also checks if attendance has already been recorded.


 2. View Attendance
Displays all attendance records stored in the system.

Example:
```bash
John: present
Mary: absent
3. Attendance Summary

Shows the total number of:

* Present students
* Absent students
